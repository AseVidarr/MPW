# MPW v2.2.0 Alpha 16 – erste reiterspezifische Korrekturen

20 feste QLabel-Texte in EN/FR/ES/IT ergänzt. Keine Änderung an Datenbank oder Geschäftslogik.

Diese Version schließt **nicht** alle vom Anwender gemeldeten Lücken. Dynamische Anzeigen und weitere Texte bleiben offen.

Prüfung: Python-Syntax, Übersetzungseinträge und ZIP-Integrität. Windows-UI-Test ausstehend.

- Gespeichertes Setup

- Backup läuft …
