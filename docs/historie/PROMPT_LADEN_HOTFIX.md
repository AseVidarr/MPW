# MPW v2.2.0 RC1 – Prompt laden Hotfix

Im AI Prompt Launcher Band und Ziel-Song wählen. Unter „Gespeicherte Prompt-Versionen“ eine Version markieren und „Gespeicherten Prompt laden“ anklicken oder doppelklicken. STYLE und LYRICS werden in die beiden AI-Editoren geladen. Bestehende Editorinhalte werden nur nach Bestätigung ersetzt. Der aktive Song und gespeicherte Versionen bleiben unverändert. Anschließend kann über „Als neue Version speichern“ eine neue Version angelegt werden.

Die bestehende Aktion „Version B in Song-Editor übernehmen“ bleibt unverändert und ist eine andere Funktion: Sie aktualisiert nach Bestätigung den aktiven Song-Prompt und legt vorher eine Sicherungsversion an.

Schaltflächenbeschriftung und Meldungen des neuen Dialogs werden für DE/EN/FR/ES/IT bereitgestellt. Keine Datenbankmigration erforderlich.
